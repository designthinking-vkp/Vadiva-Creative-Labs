Grade 1 · Ages 6–7

Play-Based Overview  |  Manual only · No machines · No detailed week table

Makedo Invent KitAir-Dry ClayPaper CraftHand Sewing Intro
CBSE Level 1 Pre-Vocational: fine motor, creative expression, material awareness. G1 follows a light theme-based overview — not a week-by-week table. Individual outcome: Mini Exhibition at Week 15 (no shared capstone).
15-Week Overview (Play-Based — No detailed week-by-week table)
Weeks 1–3

Material Exploration

  • Touch & feel: paper, clay, cardboard, Makedo pieces
  • Tear, fold, roll paper (builds finger strength)
  • First Makedo connection: Sawtool + connect two cardboard cards
✓ Sensory awareness · Makedo familiarity · Lab confidence
Weeks 4–5

Clay & Pottery Play

  • Pinch, roll, flatten air-dry clay
  • Make an animal or fruit shape
  • Teacher-demo coil bowl; students try their own
✓ Shape-making · Texture awareness · Clay handling
Weeks 6–7

Makedo Building

  • Build a cardboard house using Makedo connectors + re-clips
  • Build a cardboard car or bus
  • Decorate with crayons, stickers, paper windows
✓ 3D construction · Tool confidence · Geometric thinking
Weeks 8–9

Soft Toy & Sewing Intro

  • Thread a large plastic needle (with help)
  • Running stitch on a felt strip (practice)
  • Join two felt pieces into a fish or bird shape
✓ Fine motor · Sewing intro · Imagination
Weeks 10–11

Story & Character

  • Draw a story character
  • Make the character with felt + Makedo cardboard
  • Match toy to a 3-sentence story; act it out
✓ Narrative thinking · Character design · Confidence
Weeks 12–13

Decorate & Fix

  • Add buttons, beads, paint to soft toy
  • Clay pendant: roll, poke hole, decorate
  • Identify one thing to fix on any earlier work; fix it
✓ Aesthetics · Iteration mindset · Quality focus
Weeks 14–15

Mini Exhibition & Portfolio

  • Set up a display of all work from the term
  • Each child explains 2 items in 2 sentences to visitors
  • Teacher + parent feedback; sticker voting; portfolio photos
✓ Communication · Reflection · Pride of craft
Assessment

Observation-Based (No Tests)

Participation & engagement Makedo tool handling Clay / craft quality Ability to follow steps Verbal explanation (1–2 sentences) Portfolio completeness

Grade 2 · Ages 7–8

Play → Purpose → Problem-Solving  |  Manual tools · Makedo · Clay

Toy & Game DesignPotteryRecycled CraftHand Sewing
CBSE Level 2 Pre-Vocational: purposeful making, rule logic, material reuse. G2 follows a light theme-based overview. Individual outcome: Game Fair at Week 15 (no shared capstone).
15-Week Overview (Play-Based — No detailed week-by-week table)
Weeks 1–3

Toy & Game Exploration

  • Disassemble a simple toy to see its parts
  • Build a Makedo rolling cylinder; test on a ramp
  • Make a moveable-arm Makedo figure using re-clips as hinges
✓ Systems thinking · Motion understanding · Mechanical curiosity
Weeks 4–6

Board Game Design

  • Invent 3 game rules on paper; sketch the board layout
  • Build the board with Makedo cardboard panels; add paths, hazards, rewards
  • Swap and play each other's games; give 'one change' feedback
✓ Logical sequencing · Rule writing · Iteration
Weeks 7–8

Clay Pottery

  • Coil bowl + slab tile using air-dry clay
  • Make a useful object: pen stand or small bowl
  • Texture stamps with Makedo pieces pressed into clay
✓ Form control · Functional thinking · Cultural craft
Weeks 9–10

Recycled Craft & Sewing

  • Transform a bottle or box into something useful (Makedo + paint)
  • Running stitch: join two felt squares into a small pouch
  • Stuff and close the pouch; decorate with buttons
✓ Sustainability · Dexterity · Upcycling
Weeks 11–12

Free Make & Improve

  • Open build session: make anything using any available material
  • Review all work; fix one weak or incomplete item
  • Peer feedback: 2 compliments + 1 suggestion
✓ Creative confidence · Self-assessment · Problem-solving
Weeks 13–14

Game Fair Preparation

  • Finalise and beautify board game; write rule booklet
  • Teach the game to a Grade 1 student (cross-grade session)
  • Practise explaining: 'This is how you play…'
✓ Teaching skills · Communication · Cross-grade empathy
Weeks 14–15

Game Fair & Portfolio

  • Host a Game Fair: invite Grade 1 to play G2 games
  • Each student presents 2 items: game + one craft
  • Portfolio: photos + teacher observation + 2-sentence student reflection
✓ Confidence · Public communication · Portfolio completion
Assessment

Observation-Based (No Tests)

Participation & engagement Makedo tool handling Clay / craft quality Ability to follow steps Verbal explanation (1–2 sentences) Portfolio completeness

📒 Design Rule

Every grade is in exactly one project. No grade carries two capstones. Every capstone week is a regular 90-min session. Week 15 is always the outcome event.
